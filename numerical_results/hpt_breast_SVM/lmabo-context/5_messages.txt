**Justification:**

1.  **Persistent Exploitation Failure:** The objective function value ($f_{min} = -0.945$) got stuck very early (N=11) and never improved over the remaining 49 iterations, despite numerous attempts using highly exploitative functions (PI, LogEI, PosMean) when the model was stable. This is characteristic of a function that heavily weights the predictive standard deviation ($\sigma(x)$).
3.  **UCB Behavior:** UCB maximizes $\mu(x) + \beta \sigma(x)$. If $\beta$ is set high, UCB aggressively samples regions of high uncertainty, even if the predicted mean ($\mu$) is not optimal. This behavior perfectly explains the constant destabilization of the GP model and the failure to converge locally, as the function is always drawn away from the known optimum to test high-variance regions.
